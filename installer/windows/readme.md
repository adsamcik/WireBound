# Before installation

- Close WireBound if it is currently running.
- Setup installs the application for the current Windows user; administrator access is not required for the main application.
- The optional elevated monitoring helper may request approval later, when you enable per-application network tracking.

# Updates and repairs

Future releases can be downloaded from WireBound's Settings page and installed with **Restart & Install**.

Re-running Setup repairs the application without deleting monitoring history. Persistent data is stored separately under `%LOCALAPPDATA%\WireBoundData`.
